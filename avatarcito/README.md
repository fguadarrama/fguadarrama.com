# Francisco Guadarrama — avatar interaction

Sitio estático listo para GitHub Pages.

## Publicación

1. Crea un repositorio nuevo en GitHub.
2. Sube `index.html`, `styles.css`, `script.js` y `avatar.webp` a la raíz.
3. Abre **Settings → Pages**.
4. Selecciona **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
5. Guarda y espera a que GitHub publique la URL.

La animación de apertura usa los parámetros del archivo `image-open-tilt` incluido en los ZIP proporcionados.
